# Commands tests/test_pack_instructions_live_gc.py may EXECUTE against a real
# gc in a throwaway city, one per line, as the words that follow the binding.
#
# The bar for a line here is that running the command in a city that has
# nothing set up performs no effect outside that city: no network, no writes
# beyond the scratch city, nothing published. It is hand-written because that
# is not a property of the directory tree.
#
# All four wrappers end in `exec gc sling`, which dispatches a formula to an
# agent -- an effect, and not a small one. The three below stop well short of
# it: each takes a positional argument and prints its help on an empty one.

pr blast-radius   # empty first arg -> prints help, exit 2
pr plan           # empty first arg -> prints help, exit 2
pr review         # empty first arg -> prints help, exit 2

# `pr ship` is NOT here, and the reason is worth reading before adding it
# back. It takes no positional, so the only thing between a bare invocation
# and `exec gc sling` is its `--rig <name> required` check -- and that check
# passes when GC_RIG is set. gc SETS GC_RIG: measured in this suite's own
# scratch city, a command receives GC_RIG=demo, because the city write_city
# builds has one rig. So `gc <binding> pr ship` with no arguments reaches the
# dispatch, and it was listed here on the strength of reading the wrapper
# rather than running it. It failed in the scratch city only because no
# `polecat` agent exists there, which is not a property this file may rely
# on: any city that has one would have been slung a formula by its test
# suite.
